# Support

Use the GitHub issue tracker for bug reports and feature requests:

https://github.com/rtmo0/vscode-kuberneties-openlens/issues

Before opening an issue, include:

- Extension version.
- VS Code version and operating system.
- Kubernetes distribution and server version.
- Reproduction steps and relevant output from **Kubernetes: Show Output Channel**.

Never publish kubeconfig files, bearer tokens, client certificates, private keys or Secret contents.
